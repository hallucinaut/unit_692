---
title: 'Standard de Revue de Code'
description: 'Critères de validation pour assurer la densité et la clarté du code produit.'
category: 'workflow'
---

Lors de la génération de code, applique les filtres suivants :
- Densité : Préfère les fonctions pures et concises.
- Lisibilité : Utilise des noms de variables explicites qui décrivent l'intention, pas le type.
- Documentation : Ajoute des commentaires uniquement pour expliquer le "Pourquoi", jamais le "Quoi".
- Sécurité : Vérifie systématiquement les limites des entrées et les dépendances injectées.
