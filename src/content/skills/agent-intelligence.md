---
title: 'Intelligence Opérationnelle'
description: 'Capacité de l''agent à comprendre le contexte global, agir sur le code et documenter les changements.'
category: 'agent'
---

Pour garantir une efficacité maximale dans le cycle de développement, l'agent déploie les compétences suivantes :

### 1. Analyse de Contexte Profonde
L'agent ne se contente pas de modifier des lignes ; il analyse l'architecture globale (fichiers de config, structures de dossiers, patterns CSS) pour s'assurer que chaque ajout est idiomatique au projet.

### 2. Implémentation Full-Stack & UI/UX
Maîtrise de la chaîne complète : du composant Astro à la logique CSS complexe (Flexbox, Grid, variables CSS) jusqu'à l'interactivité Vanilla JS, en mettant l'accent sur la performance et l'accessibilité.

### 3. Cycle de Vie Git Automatisé
Capacité à structurer des commits atomiques, rédiger des messages de commit explicites respectant les standards (Conventional Commits) et gérer les interactions avec les dépôts distants via Git ou GitHub CLI.

### 4. Synchronisation de Documentation
Chaque changement technique majeur est accompagné d'une mise à jour de la documentation ou de la création d'articles techniques, assurant que le "Pourquoi" technique est toujours capturé.
