Welcome to my blog! I'm excited to share my journey of learning Astro and building websites.

## What is Astro?

Astro is a web framework for building fast, content-focused websites. It helps you ship less JavaScript to the browser and provides a great developer experience.

## Why choose Astro?

- **Fast Performance**: Astro ships almost no JavaScript by default
- **Component-based**: Use your favorite components (React, Vue, Svelte, etc.)
- **Content-driven**: Perfect for blogs, documentation, and marketing sites
- **Modern**: Built with the latest web standards
