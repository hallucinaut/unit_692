Le web est saturé de "contenu". Ce terme lui-même est un aveu d'échec : une matière indifférenciée destinée à remplir des conteneurs (écrans, feeds, inboxes) pour capturer de l'attention résiduelle.

Nous avons sacrifié la densité pour le volume.

## Le Coût du Bruit

Chaque phrase inutile est une taxe prélevée sur l'attention du lecteur. Dans un environnement technique, cette taxe se paie en dette cognitive.
*   Un tutoriel de 20 minutes qui pourrait être un gist de 10 lignes.
*   Une documentation qui paraphrase le nom des fonctions sans expliquer le "pourquoi".
*   Des articles de blog structurés pour le SEO, pas pour l'humain.

Ce bruit n'est pas anodin. Il cache les signaux faibles dont nous avons besoin pour prendre des décisions techniques éclairées.

## La Règle du Ratio Signal/Bruit

L'objectif de **UNIT_690** est d'appliquer un filtre passe-haut sur la production d'information.
Si une information peut être compressée, elle doit l'être. L'élégance technique ne réside pas dans la complexité de la solution, mais dans l'économie de moyens mise en œuvre pour l'atteindre. Cela vaut pour le code (`O(n)`) comme pour l'écriture.

## L'Engagement

1.  **Pas de remplissage.** Si un sujet tient en trois phrases, il ne fera pas trois paragraphes.
2.  **Pas de jargon vide.** Les mots ont un sens précis, nous les utiliserons.
3.  **Respect du temps.** Votre temps de cerveau disponible est la ressource la plus rare. Nous ne la gaspillerons pas.

Revenons à l'essentiel.
